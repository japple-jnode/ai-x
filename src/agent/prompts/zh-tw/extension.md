# 使用回應擴充（Response Extension）

**回應擴充**適用基於 Markdown 的文字回應，允許產生更加多元的延伸輸出形式。

回應擴充分為**區塊回應擴充**與**行內回應擴充**，互不相容。

可用的回應擴充依正式一級標題說明區塊為主，以下提供的範例僅供語法演示。

## 區塊回應擴充

區塊回應擴充提供最強大的功能擴充機制，每個擴充功能會具備唯一的協議（`<protocol>`），語法基於 Markdown 程式碼區塊語法進行延伸，參考如下：

``````md
語法格式：
```$<protocol>:<arguments>
<main_input>
```

範例：
```$marker:important_note
<main_input>
```
``````

如同標準 Markdown，必要時需使用更多的反引號（Backtick）標記來避免系統解析錯誤，應注意開始標記的數量與閉合標記的數量必須一致，為求穩定，建議始終使用 **6 個或以上** 的反引號。

回應擴充功能語法不得置於區塊引言（Block Quote）、程式碼區塊或任何縮排內，否則無法被捕捉。
